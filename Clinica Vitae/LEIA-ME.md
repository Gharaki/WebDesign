# Clínica Vitae | FACENS

Site institucional de uma clínica médica, desenvolvido como projeto acadêmico para a disciplina de Web Design da FACENS.

O objetivo é apresentar informações sobre a clínica, suas especialidades, equipe médica e convênios, além de facilitar o acesso às informações de contato e ao formulário de solicitação de agendamento.

## 🎯 Objetivo do projeto

Desenvolver uma página web organizada, intuitiva e visualmente consistente, aplicando os conhecimentos de HTML e CSS adquiridos durante a disciplina.

## ✨ Funcionalidades

- **Página inicial:** apresentação da clínica e acesso ao agendamento.
- **Diferenciais:** destaque das características e dos serviços oferecidos.
- **Sobre a clínica:** apresentação da missão, visão e valores.
- **Equipe médica:** apresentação dos profissionais e suas especialidades.
- **Agendamento:** formulário para preenchimento dos dados do paciente e da consulta.
- **Convênios aceitos:** exibição dos convênios disponíveis.
- **Depoimentos:** seção demonstrativa de avaliações de pacientes.
- **Perguntas frequentes:** respostas expansíveis para dúvidas comuns.
- **Contato:** informações de atendimento e canais de comunicação.
- **Dicas de saúde:** conteúdo informativo para os visitantes.
- **Estrutura da clínica:** apresentação dos ambientes de atendimento.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização semântica do conteúdo.
- **CSS3:** estilização, cores, espaçamentos, alinhamentos e organização dos componentes.
- **JavaScript:** arquivo preparado para futuras funcionalidades e melhorias interativas.

## 🎨 Decisões de desenvolvimento

- Separação do HTML e do CSS em arquivos distintos para facilitar a manutenção.
- Utilização de IDs e âncoras para navegação entre as seções da página.
- Uso de Flexbox para alinhamento e distribuição de elementos.
- Criação de classes reutilizáveis para padronizar os componentes visuais.
- Aplicação de uma identidade visual consistente, com tons de azul e elementos de interface padronizados.
- Utilização de elementos nativos do HTML para formulários e perguntas frequentes.
